משנים קוד — אבל רק בתוך הבלוק המסומן

בקובץ T2_mouse_starter.ino יש בלוק אחד שמסומן TUNING BLOCK — כל השורות של הכרטיסייה הזאת גרות בתוכו: BED_MODE, INVERT_X, INVERT_Y ו-DEBOUNCE_MS. כל מה שמתחת לבלוק הוא מוח העכבר — שם לא נוגעים.

💻

הערכים של תחילת הכרטיסייה

🖱️ T2_mouse_starter.ino 
// how the cursor responds
#define INVERT_X        false           // true flips left-right
#define INVERT_Y        false           // true flips up-down
// true = extra smoothing for soft surfaces
#define BED_MODE        false

// how long a button must be steady before it counts (raise if clicks double)
const unsigned long DEBOUNCE_MS = 8;

אלה הערכים שיש עכשיו בקובץ. אם משהו מתבלבל בהמשך — אלה המספרים שאליהם חוזרים.

📋

מה עושים

✓ 1

עובדים עם העכבר דקה שלמה על משטח הבד — מזרן או שמיכה — בדיוק כמו שהוא עכשיו, עם BED_MODE כבוי. שמים לב מתי הסמן קופץ: בדרך כלל בדיוק כשהבד מתקפל מתחת לעכבר.

הדקה הזאת היא נקודת ההשוואה — בלעדיה קשה להרגיש בשלב הבא מה באמת השתנה.

✓ 2

מבקשים מקלוד קוד להפוך את BED_MODE ל-true, מעלים לעכבר ועובדים שוב את אותה דקה על אותו משטח.

ההחלקה מרגישה רכה יותר וקפיצות קטנות נעלמות. ביושר: זה ריכוך, לא קסם — תזוזה גדולה מאוד של הבד עדיין תקפיץ את הסמן.

✓ 3

מחליטים אם מצב המיטה נשאר: הוא מחליק את התנועה אבל מרגיש קצת פחות חד. אין תשובה נכונה — זו הבחירה של היד שלכם. מסמנים אותה כאן:

🛏️

נשאר דולק

✓ נבחר

BED_MODE = true

התנועה רכה וזורמת על הבד. בוחרים בזה כשהקפיצות הקטנות מפריעות יותר מקצת החדות שהולכת.

🎯

חוזר כבוי

✓ נבחר

BED_MODE = false

הסמן חד ועונה מיד. בוחרים בזה כשהיד מעדיפה דיוק והקפיצות הקטנות כמעט לא מפריעות.

הבחירה שמסומנת כאן והשורה בקובץ צריכות להגיד אותו דבר. אם הבחירה היא כבוי — מבקשים מקלוד קוד להחזיר את BED_MODE ל-false ומעלים שוב.

✓ 4

בודקים את הצירים: יש ידיים ויש תנוחות שכיבה שבהן ציר הפוך דווקא קל יותר. מבקשים מקלוד קוד להפוך את INVERT_Y ל-true, מעלים ומנסים דקה על הבד.

היפוך שעוזר נשאר בקוד; היפוך שמבלבל חוזר מיד ל-false. את אותו ניסוי אפשר לעשות גם עם INVERT_X.

✓ 5

אם לחיצה אחת נספרת לפעמים כשתי לחיצות — מבקשים מקלוד קוד להעלות קצת את DEBOUNCE_MS — למשל מ-8 ל-12 — ומעלים שוב.

המספר הזה אומר כמה זמן כפתור צריך להיות יציב עד שהלחיצה נספרת. מעלים בקפיצות קטנות — מספר גדול מדי מאבד לחיצות מהירות.
