מעלים את קוד בדיקת המנועים
מתקינים שתי ספריות ומעלים לרחפן את הקוד שבודק את המנועים.
שלב 9 מתוך 14
[איור: הרחפן מונח על השולחן בלי סוללה ובלי מדחפים, וכבל USB עובר ממנו אל מחשב נייד פתוח. בצד מונחת שקית חסינת אש סגורה ובתוכה הסוללה.]
USB בפנים = סוללה בחוץ: הכבל מתחבר לשקע ה-USB של הלוח, בוחרים מהירות 115200 ומחזיקים את כפתור ה-BOOT בזמן ההעלאה. הסוללה מחכה בשקית.
📋
מה עושים
1. בסרגל הצד של סייר הקבצים לוחצים על Google Drive ואז הולכים ל-My Drive ← Arduino_Projects.
2. נכנסים לתיקייה עם הכינוי שלכם.
3. בתוכה יוצרים תיקייה חדשה בשם Project_8_Tiny_Quadcopter.
4. פותחים יחד עם המורה את קלוד קוד ומגדירים אותו לעבוד בתיקייה החדשה.
5. מסתכלים על הרחפן ומוודאים שהסוללה לא מחוברת — היא נמצאת אצל המורה. מחברים את כבל ה-USB ללוח ה-ESP32 שעל הרחפן.
6. ב-Arduino IDE מכוונים שלוש הגדרות בתפריט Tools:
לוח
Tools → Board → ESP32 Arduino → DOIT ESP32 DEVKIT V1
יציאה
Tools → Port
בוחרים את יציאת ה-COM שנוספה כשחיברתם את הכבל.
מהירות
Tools → Upload Speed → 115200
(מהירות נמוכה יותר — פחות העלאות שנכשלות עם כבלים זולים).
בפרויקטים 5 ו-6 בחרתם ESP32 Dev Module. כאן בוחרים את הלוח של הרחפן — DOIT ESP32 DEVKIT V1.
7. נכנסים ל-Sketch → Include Library → Manage Libraries, כותבים בחיפוש Adafruit MPU6050 ומתקינים. כשנפתח חלון ששואל על ספריות נוספות — לוחצים Install all.אחר כך מחפשים Adafruit Unified Sensor ובודקים שכתוב לידה INSTALLED. זו אותה התקנה כמו הספריות של פרויקט 6. שתי הספריות האלה שייכות ל-MPU6050 — החיישן שמרגיש לאן זה למטה — ומשמשות את קוד התעופה בכרטיסיות הבאות.
8. מעתיקים את הקובץ 00_motor_test.ino מתיקיית המורה לתיקיית פרויקט 8 שלכם ופותחים אותו ב-File → Open.קוראים את הכותרת בראש הקובץ: כתוב בה מה הקוד עושה ושהוא רץ בלי מדחפים. המורה כבר הגדיר בקובץ את מספר העמדה שלכם (STATION), כך שרשת ה-Wi-Fi של הרחפן תיקרא DRONE-01 עד DRONE-08 לפי המספר שלכם — אותו שם שכתוב על המדבקה שעל הרחפן.
9. לוחצים על Upload ומחכים שתופיע למטה השורה Hard resetting via RTS pin...אם המסך תקוע על Connecting... — מחזיקים את כפתור ה-BOOT שעל הלוח לחוץ עד שהנקודות מתחילות לזוז.
10. פותחים את הצג הטורי (Tools → Serial Monitor), בוחרים מהירות 115200 וקוראים את הכותרת שהקוד מדפיס.משווים את שם הרשת שבצג הטורי לשם שעל מדבקת הרחפן — הם חייבים להיות זהים. רושמים את שם הרשת על הכרטיסייה, בשורה שלמטה. הסיסמה של הרשת נמצאת על כרטיס העמדה שלכם ולא נרשמת כאן.

מה רואים אם הכול תקין

אצלכם מופיע מספר העמדה שלכם — לא בהכרח DRONE-01.

🪄 תקועים?
●אם לא מופיעה שום יציאת COM: הכבל אולי כבל טעינה בלבד — מחליפים כבל ובודקים שוב. אם גם הכבל השני לא עוזר, חסר במחשב הזה מנהל ההתקן של שבב ה-USB (CP2102) — קוראים למורה.
●אם מופיע טקסט שגיאה אדום שמזכיר את ledcAttach: חבילת ה-ESP32 שבמחשב ישנה — מעדכנים ב-Boards Manager את esp32 by Espressif לגרסה 3.
●אם ההעלאה נשארת על Connecting...: מחזיקים את כפתור ה-BOOT. אם זה לא עוזר — מנתקים את ה-USB, מחברים שוב ומעלים מחדש.
●עדיין תקועים? קוראים למורה.
