Yon is building a research-backed framework for designing differentiated PBL projects in a robotics workshop for students with emotional and behavioral disorders.

**Current state (2026-04-10):** Literature corpus now 66 verified + row 69 added during Phase B + 12 Partial/Corrected (two of which were re-corrected in Phase A: P2 → Rosen et al. 2014 and P11 → Gibbs 2023). Full-text files for 65 of 66 at `articles_full_texts/` (only Tomlinson 2014 book missing). The overall framework has evolved into a more concrete program — the **Arduino PBL Program for Agourim School** — see [project_arduino_pbl_program.md](project_arduino_pbl_program.md) for its detailed current state. That project has Phase A (literature read) and Phase B (principle distillation) complete; Phase C (master document assembly) is next.

The earlier distilled principles from the framework document have been superseded by the **9 design principles** in `Arduino_Principles.md` — which merge and extend them with full citation evidence.
