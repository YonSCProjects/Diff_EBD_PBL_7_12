המהירויות שלך

מכווננים עם קלוד קוד את שלוש המהירויות של הסמן עד שהן מתאימות ליד שלכם ובוחרים באיזו מהירות העכבר מתעורר.

שלב 2 מתוך 633%
🧠
משנים קוד — אבל רק בתוך בלוק הכוונון

בקובץ T2_mouse_starter.ino יש בלוק אחד שמסומן TUNING BLOCK — שם גרות כל ההחלטות האישיות. כל מה שמתחתיו הוא המוח של העכבר: החיישן, הכפתורים, ה-Bluetooth. שם לא נוגעים. בכרטיסייה הזאת משנים רק שתי שורות: CPI_LEVELS ו-START_LEVEL.

💻

ככה נראות המהירויות עכשיו בקוד

📄 T2_mouse_starter.ino 
// the three speed levels the rear roller steps through (counts per inch)
const int CPI_LEVELS[3] = { 400, 800, 1600 };
const int START_LEVEL   = 1;            // 0 = slowest, 2 = fastest

שלושת המספרים ב-CPI_LEVELS הם שלוש מהירויות הסמן: מספר קטן — סמן איטי ומדויק, מספר גדול — סמן שטס על המסך. גלגלת המהירות האחורית עוברת ביניהם והלד שמאיר מראה באיזו מהירות אתם. השורה START_LEVEL קובעת באיזו מהשלוש העכבר מתעורר כשמדליקים אותו.

🔀

בוחרים — באיזו מהירות העכבר מתעורר

עכשיו בקוד כתוב START_LEVEL = 1 — העכבר מתעורר במהירות האמצעית. מסמנים מה מתאים ליד שלכם; את הבחירה כותבים לקוד בשלב 3.

🐢

✓ נבחר

START_LEVEL = 0

העכבר מתעורר במהירות האיטית ביותר. מתאים למי שאוהב דיוק — כל תנועה קטנה נשארת קטנה.

⚖️

ב׳ · מתעורר באמצע

✓ נבחר

START_LEVEL = 1

ככה הקוד מגיע מהמסלול הראשון. נקודת פתיחה טובה כשעדיין לא בטוחים.

🐇

ג׳ · מתעורר מהיר

✓ נבחר

START_LEVEL = 2

העכבר מתעורר במהירות המהירה ביותר. מתאים למי שעובר הרבה בין קצוות המסך.

💻

ככה מבקשים מקלוד קוד

כותבים לקלוד קוד בעברית פשוטה מה להחליף. למשל:

שנה את שלוש המהירויות ב-CPI_LEVELS ל-300, 600 ו-1200.
המהירות האמצעית מהירה מדי בשבילי — תוריד אותה ל-600.
שנה את START_LEVEL ל-0 כדי שהעכבר יתעורר במהירות האיטית.

קלוד קוד משנה את הקובץ — ההעלאה לעכבר היא שלכם, עם הכבל ועם Upload.

🎯
חוק הכוונון

משנים מספר אחד בכל פעם ומרגישים לפני שמשנים עוד. ככה יודעים בדיוק איזה שינוי עשה את ההבדל.

📋

מה עושים

✓ 1

מדליקים את העכבר ועוברים עם גלגלת המהירות בין שלוש המהירויות על משטח הבד — שמיכה מקופלת היא משטח מצוין. שואלים על כל אחת: איטית מדי? מהירה מדי? כמעט מתאימה?

הלד שמאיר מראה באיזו מהירות אתם עכשיו.

✓ 2

💻 מבקשים מקלוד קוד לשנות מספר אחד — כמו בדוגמאות שלמעלה. מחברים את הכבל, לוחצים Upload, מנתקים ומרגישים שוב על הבד. חוזרים על הסיבוב עד ששלוש המהירויות מרגישות נכון.

הכבל נחוץ רק לרגע ההעלאה. אחרי שמנתקים העכבר חוזר לעבוד בלי חוט.

✓ 3

מסמנים למעלה באיזו מהירות העכבר מתעורר ומבקשים מקלוד קוד לכתוב את הבחירה בשורה של START_LEVEL. מעלים עוד פעם אחת.

בודקים עם המתג: מכבים, מדליקים ומרגישים באיזו מהירות הסמן מתעורר.

✓ 4

כותבים למטה בכרטיס את שלושת המספרים המנצחים — אלה שנשארו בקוד בסוף הכוונון.
