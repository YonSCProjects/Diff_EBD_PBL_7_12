מכינים את המחשב — ספריות ראשונות
בודקים שה-ESP32 עדיין מדבר עם המחשב ושתי הספריות של הפרויקט כבר במקומן.
שלב 1 מתוך 8
📋
מה עושים
1. מורידים את ה-ESP32 מהמכונית של פרויקט 5: מנתקים את ששת חוטי הג'אמפר מהלוח ומשחררים את הסקוטש. מחברים את ה-ESP32 למחשב עם כבל ה-USB שלו.המכונית עצמה נשארת שלמה — רק הלוח יוצא ממנה. את הברדבורד והחיישנים מחברים בכרטיסייה הבאה.
2. בדיקה מהירה: פותחים ב-Arduino IDE את הקובץ 00_esp32_test.ino מתיקיית פרויקט 5 ולוחצים על Upload. הלד הכחול על הלוח מהבהב.בודקים ש-Tools → Board עדיין על ESP32 Dev Module ושיציאת ה-COM נבחרה. אם משהו לא עובד — כרטיסייה 1 של פרויקט 5 מסבירה את ההתקנה.
3. נכנסים ל-Sketch → Include Library → Manage Libraries ובודקים ששתי הספריות של הפרויקט כבר כאן: מחפשים DHT sensor library (זו שכתוב עליה by Adafruit) ואחר כך Adafruit SSD1306 — ליד שתיהן כתוב INSTALLED.המורה כבר התקין את הספריות בכל עמדה. חסרה אחת? קוראים למורה.
