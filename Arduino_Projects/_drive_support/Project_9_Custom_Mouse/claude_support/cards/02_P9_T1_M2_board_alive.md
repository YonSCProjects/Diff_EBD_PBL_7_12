הלוח מתעורר לחיים
מחברים את לוח ה-ESP32-S3 למחשב, מעלים את הקוד הראשון ורואים את הלד שעל הלוח מהבהב.
שלב 2 מתוך 12
📋
מה עושים
1. מניחים את לוח ה-ESP32-S3 על הברדבורד, מעל החריץ שבאמצע — בדיוק כמו לוח ה-ESP32 בפרויקטים 5 ו-6. דוחפים בעדינות ובאופן שווה, קצת מכל צד, עד שכל הרגליים נכנסות עד הסוף.
2. מחברים כבל USB-C מהלוח למחשב.
3. פותחים ב-Arduino IDE את הקוד 00_hello_blink מתיקיית המורה (File → Open) ומכוונים שתי הגדרות בתפריט Tools:
לוח
Tools → Board → esp32 → ESP32S3 Dev Module
יציאה
Tools → Port
בוחרים את היציאה שנוספה כשחיברתם את הכבל.
אחר כך לוחצים Upload ומחכים לסיום ההעלאה.לקוד הזה לא צריך שום ספרייה ושום הגדרת USB מיוחדת — פשוט מעלים.
🔁
טקס ה-BOOT — אם ההעלאה לא מתחילה
1. מחזיקים את כפתור BOOT לחוץ
2. לוחצים לחיצה קצרה על RESET
3. משחררים את BOOT
4. לוחצים שוב על Upload
הטקס הזה מכניס את הלוח למצב העלאה — והוא חוזר גם בכרטיסיות הבאות.
4. מסתכלים על הלוח: הלד הקטן שבנוי עליו מאיר ירוק, אחר כך כחול, אחר כך כתום — נכבה לרגע וחוזר מההתחלה. הלוח חי.לד ה-RGB הזה בנוי על הלוח עצמו — לכן הקוד הראשון רץ בלי שום חיווט.
5. רק אחרי שהלד מהבהב: יוצרים ב-Google Drive, בתוך התיקייה עם הכינוי שלכם, תיקייה חדשה בשם Project_9_Custom_Mouse ומגדירים את קלוד קוד לעבוד בה.קודם חומרה, אחר כך תיקיות — זה הסדר בכל פרויקט.
👀
מה רואים אם הכול תקין
הלד הקטן שעל הלוח מאיר ירוק, אחר כך כחול, אחר כך כתום, נכבה לרגע — וחוזר מההתחלה, שוב ושוב.
בקוד כתוב delay(400) — בגלל זה כל צבע נשאר בערך ארבע עשיריות שנייה.

🪄 תקועים?
●אם לא מופיעה שום יציאה ב-Tools → Port: בודקים שהכבל נכנס עד הסוף בשני הצדדים. כבל של טעינה בלבד לא מעביר נתונים — מנסים כבל אחר.
●אם ההעלאה נכשלת מיד: בודקים שב-Tools → Board נבחר ESP32S3 Dev Module — לא לוח אחר מהרשימה.
●אם ההעלאה לא מתחילה בכלל: עושים את טקס ה-BOOT מהקופסה שלמעלה ומנסים שוב.
●עדיין תקועים? קוראים למורה.
