זה השלב שחיכיתם לו. בשלב הקודם הלד כבר מאיר כשמשהו מתקרב — עכשיו מוסיפים זמזם, אותו זמזם פּיֵזו שכבר מכירים מפרויקט 2. כשהמרחק יקטן מ-20 ס"מ, הלד יאיר וגם הזמזם יצפצף — אור וקול ביחד. בסוף השלב הזה יש אזעקת קרבה שלמה.

מה עושים
השלב הזה בנוי משני חלקים: קודם מחווטים את הזמזם ואז מעלים את הקוד של האזעקה המלאה.
חלק א' — מחווטים את הזמזם
1. בוחרים את הזמזם פּיֵזו הקטן ממגש החלקים. הוא העגול והשטוח עם שתי רגליים — אותו זמזם מפרויקט 2.
2. מכניסים את הזמזם לברדבורד כך ששתי רגליו בטורים שונים.
3. מחברים רגל אחת של הזמזם לחיבור דיגיטלי 8 של הארדואינו בעזרת חוט ג'אמפר.
4. מחברים את הרגל השנייה של הזמזם ל-GND בעזרת חוט ג'אמפר.
5. הזמזם הקטן הזה לא צריך נגד ואין לו צד חיובי או שלילי — אפשר לחבר כל רגל לכל צד.
6. החיישן והלד נשארים בדיוק כמו שהם — לא נוגעים בהם.
חלק ב' — מעלים את האזעקה המלאה
1. פותחים את הקובץ 03_distance_full_alarm.ino ב-Arduino IDE.הקובץ נמצא בתוך תיקיית פרויקט 3 שלכם, ליד הקבצים הקודמים שהעליתם.
2. לא משנים שום דבר בקוד — רק מעלים אותו.
3. לוחצים על כפתור ה-Upload.
4. מחכים להודעה Done uploading בירוק.
5. מקרבים יד לאט אל החיישן — עד פחות מ-20 ס"מ. בודקים: הלד מאיר? הזמזם מצפצף?

💻
מה חדש בקוד הזה
אפשר להציץ בקוד ב-IDE. הוא עושה בדיוק מה שהקוד הקודם עשה — מודד מרחק ומאיר את הלד כשהמרחק קטן מ-20 ס"מ — אבל נוספו בו שורות tone() ו-noTone() שמפעילות ומשתיקות את הזמזם יחד עם הלד:
03_distance_full_alarm.inoif (distanceCm < THRESHOLD_CM) {
digitalWrite(LED_PIN, HIGH); // קרוב מדי ← הלד מאיר
tone(BUZZER_PIN, ALARM_TONE); // ← שורה חדשה: הזמזם מצפצף
} else {
digitalWrite(LED_PIN, LOW); // רחוק מספיק ← הלד כבוי
noTone(BUZZER_PIN); // ← שורה חדשה: הזמזם שותק
}
זה הקוד שמופיע גם בכרטיס הקוד R5. לא צריך לכתוב או לשנות — רק מעלים ומקרבים יד.
👀
מה רואים אם הכול תקין
כשמקרבים יד אל החיישן עד פחות מ-20 ס"מ — הלד מאיר וגם הזמזם מצפצף, ביחד. כשמרחיקים את היד — הלד כבה והזמזם משתתק. המרחק עדיין מופיע במסך המעקב (Serial Monitor), בדיוק כמו קודם ולצידו ההודעה "TOO CLOSE!" כשהאזעקה פעילה.
מספר גדול כשאין כלום מול החיישן זה תקין, לא תקלה — החיישן פשוט לא שמע הד וכותב מספר גדול (למשל 999). זה אומר "רחוק", לא "שבור".
