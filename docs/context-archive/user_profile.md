Yonatan Lev El (goes by Yon) runs the robotics and programming workshop at **Agourim School**, a small Israeli special-education school for grades 7–12. The student population all share the history of not "surviving" regular primary school and carry varied diagnoses: ADHD, ODD, anxiety, depression, OCD, post-trauma. Literacy and social profiles vary widely — some students can hardly read/write, others are fluent; some deeply introverted, others extroverted; some from neglecting homes, others from highly supportive ones. Common across all: school confidence has been damaged, so the super-target of every project is **small positive empowering experiences**.

**Workshop structure:** groups of **3–8 students from the same mother class**, each on a different individual project. This means projects must maximize student independence so Yon — as a solo teacher — can rotate to students who need more guidance.

**Hardware available:** robotics-focused Arduino kits, ESP32 DevKit boards, cameras (including ESP32-CAM), car chassis with DC motors and driver boards, 3.7V LiPo batteries with chargers, LEGO robotics kits, computers.

**Coding environment:** **C++ in Arduino IDE, with Claude Code as the students' coding collaborator.** This is a first-class feature of the curriculum — the AI is a scaffold, not an afterthought. Students describe what they're trying to build and iterate with Claude Code rather than copy-pasting finished code.

**Language:** English for development work; Hebrew for student-facing materials and Ministry-facing documents. Both English and Hebrew versions are maintained — Yon explicitly wants a complete English version alongside Hebrew ("at my workshop and among my local peers we will use the Hebrew" but English is needed for external sharing).
