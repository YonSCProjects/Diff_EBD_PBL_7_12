הכפתורים שלך ושם משלו

בוחרים מה שלושת כפתורי הצד יעשו, מחליטים מה השכבה תעשה — ונותנים לעכבר את השם האמיתי שלו.

שלב 3 מתוך 650%
🧠
משנים קוד — אבל רק בתוך בלוק הכוונון

בקובץ T2_mouse_starter.ino יש בלוק אחד שמסומן TUNING BLOCK — כל מה שמותר לשנות נמצא בתוכו. כל מה שמתחתיו הוא המוח של העכבר: הפינים, החיישן, הגלגלות וה-Bluetooth. שם לא נוגעים.

💻

ככה נראות השורות שלכם עכשיו

📄 T2_mouse_starter.ino 
// ═══ TUNING BLOCK — everything you may change lives here ═══

// the name the computer sees when pairing
#define MOUSE_NAME      "P9-MOUSE"

...

// side buttons, base layer: MOUSE_BACK, MOUSE_FORWARD, MOUSE_MIDDLE,
//                           MOUSE_LEFT, MOUSE_RIGHT
#define S1_BASE         MOUSE_BACK
#define S2_BASE         MOUSE_FORWARD
#define S3_BASE         MOUSE_MIDDLE

אלה הערכים שיש עכשיו בקובץ: הכפתורים עושים אחורה, קדימה ולחיצה אמצעית — והשם הוא עדיין P9-MOUSE. בכרטיסייה הזאת שניהם הופכים לשלכם.

📋

מה עושים

✓ 1

חושבים עם המורה: מה שלוש הפעולות שהיד עושה הכי הרבה מול המחשב? למשל אחורה בדפדפן, העתקה או החלפת חלון.

לכל כפתור צד יש חמש אפשרויות מוכנות בקוד: MOUSE_BACK, MOUSE_FORWARD, MOUSE_MIDDLE, MOUSE_LEFT ו-MOUSE_RIGHT. פעולה שאין ברשימה היא רעיון בשביל קלוד קוד — מגיעים אליו בשלב 3. כותבים כאן את שלוש הפעולות שבחרתם.

✓ 2

משתמשים במה שכתבתם בשלב 1. מבקשים מקלוד קוד לשנות את S1_BASE, S2_BASE ו-S3_BASE לשלוש הפעולות שבחרתם ומעלים ללוח.

למשל: ״שנה את S1_BASE ל-MOUSE_MIDDLE — אני רוצה שהכפתור הקדמי יעשה לחיצה אמצעית.״ אחרי ההעלאה לוחצים על כל כפתור צד בתורו ובודקים שהוא עושה את הפעולה החדשה שלו.

✓ 3

לוחצים על גלגלת המהירות האחורית — לד השכבה מאיר ושלושת הכפתורים מחליפים תפקיד: נעילת גרירה, לחיצה כפולה וקפיצת מהירות. מחליטים מה השכבה תעשה בעכבר שלכם: משאירים את השלישייה הזאת או מבקשים מקלוד קוד רעיונות אחרים. כותבים כאן מה החלטתם.

רעיונות חדשים דורשים עוד קוד — וקלוד קוד יודע לכתוב אותו.

✓ 4

רגע השם: בוחרים לעכבר שם אמיתי משלו, מבקשים מקלוד קוד לשנות את MOUSE_NAME ומעלים ללוח. כותבים כאן את השם.

במחשב מוחקים את P9-MOUSE הישן מרשימת ה-Bluetooth ומחברים את השם החדש. המחשב מכיר עכשיו עכבר שקיים רק אחד ממנו בעולם.

👀
מה רואים אם הכול תקין

ברשימת ה-Bluetooth של המחשב מופיע השם שבחרתם. כל כפתור צד עושה בדיוק את הפעולה שקיבל.

את P9-MOUSE הישן כבר לא רואים ברשימה.
