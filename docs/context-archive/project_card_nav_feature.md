Built 2026-08-10 after Yon confirmed students choose paper **or** screen and many will use the screen, so on-screen cards needed a way to reach the next card.

**How it is built (do NOT hand-edit 55 cards):**
- `build_card_nav.js` (repo root) generates `card_nav.js` into each `Arduino_Projects/*/task_cards_he/` and injects `<script src="./card_nav.js"></script>` after the `support.js` tag. Idempotent; `--check` mode verifies drift. **Re-run it after adding, renaming, or retitling a task card.**
- The chain is derived from filenames (`P<n>_T<tier>_M<milestone>`), so only the branch rules are hand-declared (in `BRANCHES`).
- `support.js` is GENERATED from `dc-runtime/src/*.ts` and says "do not edit" — that is why the nav lives in a separate sibling file, not inside it.

**Design decisions (Yon approved the shape before implementation):**
- Prev/next only, **no jump-to-any-card menu** — a global menu invites skipping wiring/safety steps.
- Chains are **per tier**: T1 and T2 are alternative tracks, so they never link to each other; the 4 standalone T3 planner cards get no nav at all (their filenames lack `_M<n>_`, so the parser skips them).
- **Branch points differ per project**: P1 `tc_p1t2m2_choice` branches to 2b on option ב; P2 `tc_p2t2m2_choice` branches on option א. A generic "option B branches" rule would be wrong.

**Three guards make it inert** (all three verified with real renders):
1. inside an iframe → the review console renders cards in one, and extra DOM would shift every `blockIndex` its feedback JSON records;
2. `matchMedia('print')` → `render_cards_lib.js` `preparePage()` calls `emulateMediaType('print')` for BOTH `renderCardPdf` and `snapshotCardHtml`, so PDFs and the merged HTML bundle stay clean (the overview build uses the same helpers);
3. `@media print` CSS → clean paper when a student prints from the browser.

It mounts on `document.body`, **outside the dc React root**, so a `setState` re-render (checkbox, choice) cannot drop it.

**Consequence:** adding the script tag changed the FNV-1a `sourceHash` of all 51 chained cards — any feedback saved in the console before 2026-08-10 reads as stale. See [[card-review-console]].
