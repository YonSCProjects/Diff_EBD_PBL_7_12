# Context archive — the previous environment's working memory

These 53 files were the persistent memory of the Claude Code sessions that built most of this
project between April and August 2026. They lived **outside** the repository, at
`~/.claude/projects/c--Users-Yon-Documents-Diferential-pbl-for-BE/memory/`, which means they
would have been lost when the project moved environments. They are copied here so nothing is.

**Read `../../HANDOFF.md` first.** It is the current, reconciled account of the project and it
supersedes anything here that disagrees with it. These files are raw notes, written at different
times, for a different environment.

## How to use them

`MEMORY.md` is the index — one line per file. The rest fall into four kinds, named by prefix:

| prefix | what it holds |
| --- | --- |
| `user_` | who Yon is and how he works |
| `feedback_` | corrections and confirmed approaches — how the work should be done |
| `project_` | state and decisions on a specific piece of work |
| `reference_` | pointers to tools, kits and external resources |

The `feedback_*` files are the most durable and the most worth reading; they are standing
instructions rather than status. The `project_*` files are snapshots and age fastest —
`project_session_handoff.md` in particular is a point-in-time note, not a live document.

## Known-stale entries

- `project_session_handoff.md` — describes where one session stopped, not where the project is.
- `reference_illustration_kit.md` — the kit it describes is retired for drawing; see HANDOFF.md.
- `project_arduino_project*_built.md` — accurate for when they were written; several of their
  "deferred" items have since been done.
- Anything describing Claude Code skills, hooks or MCP wiring describes the **old** environment
  and may not apply.

Nothing here is a citation source. The research standard for this project is that only
100 %-verified references with real DOIs and authors go into program documents; see
`../../Verification_Log.md`.
