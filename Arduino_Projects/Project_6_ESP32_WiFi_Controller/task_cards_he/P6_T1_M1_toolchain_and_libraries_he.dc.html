מה עושים

✓ 1

מורידים את ה-ESP32 מהמכונית של פרויקט 5: מנתקים את ששת חוטי הג'אמפר מהלוח ומשחררים את הסקוטש. מחברים את ה-ESP32 למחשב עם כבל ה-USB שלו.המכונית עצמה נשארת שלמה — רק הלוח יוצא ממנה. את הברדבורד והחיישנים מחברים בכרטיסייה הבאה.

✓ 2

בדיקה מהירה: פותחים ב-Arduino IDE את הקובץ 00_esp32_test.ino מתיקיית פרויקט 5 ולוחצים על Upload. הלד הכחול על הלוח מהבהב.בודקים ש-Tools → Board עדיין על ESP32 Dev Module ושיציאת ה-COM נבחרה. אם משהו לא עובד — כרטיסייה 1 של פרויקט 5 מסבירה את ההתקנה.

✓ 3

נכנסים ל-Sketch → Include Library → Manage Libraries, כותבים בחיפוש DHT sensor library ומתקינים את זו שכתוב עליה by Adafruit. כשנפתח חלון ששואל על ספרייה נוספת (Adafruit Unified Sensor) — לוחצים Install all. עושים את זה יחד עם המורה בפעם הראשונה.

✓ 4

באותו חלון כותבים בחיפוש Adafruit SSD1306 ומתקינים. גם כאן נפתח חלון על ספרייה נוספת (Adafruit GFX Library) — לוחצים Install all.ליד כל ספרייה שהותקנה מופיעה התווית INSTALLED.
